# Changelog

All notable changes to Hangly for Windows are documented here.

## [1.1.0] — 2026-09-16

### Windows Native Release

- **Native Windows Desktop Overlay (`Hangly.exe`)**: Built with C# and .NET Framework 4.0 GDI+, running borderless, transparent, and TopMost on primary Windows displays.
- **Dynamic Click-Through (`WM_NCHITTEST`)**: Windows passes clicks directly to underlying apps everywhere outside the charm talisman with 0ms latency, enabling unobstructed access to browser close (`✕`), minimize, maximize, and tabs.
- **Enhanced Golden Silk Cord**: High-visibility tri-layer rendering with amber contour silhouette, radiant gold core, and spiral braid sheen.
- **New Featured Charm**: Added the Emerald Four-Leaf Lucky Clover (`clover`) with gold bezel styling.
- **Custom Application Icon**: Multi-resolution Windows `Hangly.ico` and desktop shortcut installer (`Create-Desktop-Shortcut.bat`).
- **Complete Removal of macOS/iOS dependencies**: Stripped Swift, Xcode, and Apple-specific frameworks.
- **Web Studio & Desktop Simulator**: Full local web environment on port 3030 with procedural Web Audio synthesis and AI custom charm generator.
