# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting a Vulnerability

If you discover a security vulnerability in Hangly for Windows, please report it privately through GitHub Security Advisories rather than opening a public issue.

Please include:
- A description of the issue and potential impact
- Your Windows version and architecture
- Clear steps to reproduce or proof of concept
